# EduPulse

Comprehensive EdTech Learning & Project Management Platform.

## Features
- **Interactive Multi-Language Compiler & Interpreter** (Python, JavaScript, Java, C, C++, SQL)
- **Scratch 3.0 Jigsaw Blocks AST Visualizer & Execution Tracer**
- **Student & Mentor Portals** with Live Code Telemetry
- **Role-based Authentication & Real-time Classrooms**

## Architecture
- **Frontend**: React + Vite + Tailwind CSS
- **Backend**: Node.js + Express REST API
- **Database**: MySQL with Prisma ORM
